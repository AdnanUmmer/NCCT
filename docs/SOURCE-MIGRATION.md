## Import behaviour

`python manage.py import_ncct_content` performs a reviewed, offline, atomic one-time initialization. The catalogue-v1 receipt prevents later deployments from changing admin edits or restoring deleted items. Existing products with the same model reference and existing pages/resources are preserved. This is deliberately not a bidirectional synchronizer.
